## 🚀 Getting Started

### Requirements

- Node.js 20+
- A Discord Bot Token
- Puter AI Auth Token

---

### 📦 Clone Repository

```bash
git clone https://github.com/ayadshkur10221/karwan-ai.git
cd karwan-ai
```

---

### 📥 Install Dependencies

```bash
npm install
```

---

### ⚙️ Environment Setup

Create a `.env` file in the root directory:

```env
PUTER_AUTH_TOKEN=
DISCORD_TOKEN=
```

---

### ▶️ Run the Bot

```bash
node app.js
```

or (if you use dev script):

```bash
npm run dev
```

---

## 🔑 API Setup

### Discord Bot Token

1. Go to Discord Developer Portal  
2. Create a new application  
3. Create a bot  
4. Copy the bot token  
5. Add it to `.env`:

```env
DISCORD_TOKEN=
```

---

### Puter AI Token

Get your token from Puter:

👉 https://puter.com/

Then add it:

```env
PUTER_AUTH_TOKEN=
```
