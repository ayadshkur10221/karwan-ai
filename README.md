## 🚀 Getting Started

### Requirements

- Node.js 20+
- Discord Bot Token
- Puter AI Auth Token

### Clone Repository

```bash
git clone https://github.com/ayadshkur10221/karwan-ai.git
cd karwan-ai
```

### Install Dependencies

```bash
npm install
```

### Create `.env`

Create a file called `.env` in the root directory:

```env
PUTER_AUTH_TOKEN=
DISCORD_TOKEN=
```

### Start The Bot

```bash
node app.js
```

Or if your project uses npm scripts:

```bash
npm run dev
```

---

## 🔑 Getting Tokens

### Discord Token

1. Open Discord Developer Portal
2. Create a new application
3. Create a bot
4. Copy the bot token
5. Paste it into:

```env
DISCORD_TOKEN=
```

### Puter AI Token

Get your [Puter](https://puter.com/) authentication token and place it in:

```env
PUTER_AUTH_TOKEN=
```
